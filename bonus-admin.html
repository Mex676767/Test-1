Configured bonuses

Chat transfer count

Counts chats moved from a tracked group to a different group, read from LiveChat's archive. Each license is counted on its own. Needs the admin key (the same value as SCAN_KEY in Cloudflare). Nothing is saved or changed in LiveChat or Lark.

Dates are Kuala Lumpur time. A whole month can take several minutes; leave this page open.

Check one chat first

Paste the ID of a chat you know was transferred. This shows the raw transfer messages LiveChat stored and how they were read, so you can confirm the counting before running a whole month. Message text is not shown.

One-time Lark setup

      
Create a table named Bonus Config in the main base, add the fields below, then set its table ID as LARK_TABLE_BONUS_CONFIG in Cloudflare.

      
Key, Label, Source Table ID, Source Base Token,
Username Field, Brand Field, Date Field, Display Field,
Eligibility Rule, Rule Value, Selection, Inquiry  → Text fields
Active, Amount Eligible                           → Checkbox fields
